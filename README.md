# Soundless

**Музыка без лишнего шума** · Windows и Android · `0.1.0 Beta`

## Скачать

| Платформа | Файл | Требования |
|---|---|---|
| Windows 10/11 (x64) | [Soundless_0.1.0-beta_x64-setup.exe](releases/Soundless_0.1.0-beta_x64-setup.exe) | WebView2 (ставится автоматически) |
| Android 7.0+ (arm64 / armv7) | [Soundless-0.1.0-beta.apk](releases/Soundless-0.1.0-beta.apk) | Разрешите установку из неизвестных источников |

Приложение само проверяет обновления через этот репозиторий (`update.json`) и предлагает установить новую версию.

## Возможности

- Поиск и воспроизведение: каталог вашего сервера Soundless (треки загружает администратор через Telegram-бота), открытый каталог Audius и файлы с устройства
- Бесшовное воспроизведение и кроссфейд с настраиваемой длительностью
- Караоке-текст по словам (LRCLIB): размер, видимость строк, стиль, анимация, смещение, перевод и поиск клипа
- Кастомизация: темы, акцентные цвета, Liquid Glass (размытие, прозрачность, насыщенность, преломление), шрифты (Segoe UI по умолчанию, свои шрифты из файла)
- Профили, друзья, совместимость вкусов, «сейчас слушает», уровни слушателя, статистика
- Регистрация, вход через Telegram, восстановление пароля через бота
- Windows: трей, мини-плеер поверх окон, мультимедийные клавиши, автозапуск
- Android: фоновое воспроизведение, управление из уведомления и с экрана блокировки

Ядро приложения написано на Rust (Tauri 2).

## Первый запуск

При первом запуске укажите адрес сервера Soundless (его даёт администратор), затем зарегистрируйтесь или войдите через Telegram.
