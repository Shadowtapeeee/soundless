# Soundless

**Музыка без лишнего шума** · Windows и Android · `0.1.0 Beta`

## Скачать

Установщики публикуются во вложениях к релизам: **[Releases → последняя версия](https://github.com/Shadowtapeeee/soundless/releases)**.

| Платформа | Файл | Требования |
|---|---|---|
| Windows 10/11 (x64) | `Soundless_0.1.0-beta_x64-setup.exe` | WebView2 (ставится автоматически) |
| Android 7.0+ (arm64 / armv7) | `Soundless-0.1.0-beta.apk` | Разрешите установку из неизвестных источников |

Контрольные суммы — в файле `SHA256SUMS.txt` того же релиза. Приложение само проверяет обновления через GitHub Releases и предлагает установить новую версию.

## Возможности

- **Поиск** по каталогу Soundless, Deezer, SoundCloud и Spotify (официальные API), Audius и файлам с устройства; метаданные и обложки — из Deezer/Spotify
- **Моя волна** и миксы «Для вас» по выбранным любимым артистам и похожим исполнителям, умная очередь, плейлисты по текстовому описанию
- **Плеер**: бесшовное воспроизведение, кроссфейд, нормализация громкости, прогресс-бар в виде волны трека
- **Караоке** по словам: размер, видимость строк, стиль, анимация, смещение, перевод
- **Комнаты** совместного прослушивания с синхронизацией и чатом
- **Офлайн**: загрузка треков на устройство, управление кэшем и местом
- **Статистика**: графики по дням и часам, топы, серии и достижения
- **Профиль**: аватар, баннер, обложки плейлистов, уровни, друзья и совместимость вкусов
- **Вход**: логин и пароль, Google, защита от ботов при входе и регистрации
- **Soundless Aura** — подписка с расширенными возможностями (миксы, статистика, офлайн до 10 ГБ, комнаты до 10 человек, синхронизация устройств, ранний доступ и другое)
- AMOLED-оформление, Liquid Glass, акцентные цвета и шрифты (Segoe UI по умолчанию)
- Windows: трей, мини-плеер поверх окон, мультимедийные клавиши, автозапуск
- Android: фоновое воспроизведение, управление из уведомления и с экрана блокировки

Ядро приложения написано на Rust (Tauri 2).
